About color, outlines, and shadows

A plain text field can only hold plain text — it has no way to store color, outlines, or shadow effects. That's a limitation of every text input, not this tool. The styles below keep their look anywhere because each one is a distinct set of Unicode characters, not styled letters. Only Latin letters and numbers convert; other scripts (Chinese, Cyrillic, etc.) pass through unchanged. If you need color or shadow effects, that has to be an image instead of editable text.
