About color, outlines, and shadows

A plain text field can only hold plain text — it has no way to store color, outlines, or shadow effects. That's a limitation of every text input, not this tool. The styles below keep their look anywhere because each one is a distinct set of Unicode characters, not styled letters. Most styles only convert Latin letters and numbers, passing other scripts (Chinese, Cyrillic, etc.) through unchanged — a few, like the wraparound styles, work on any script since they don't touch individual letters. If you need color or shadow effects, that has to be an image instead of editable text.
